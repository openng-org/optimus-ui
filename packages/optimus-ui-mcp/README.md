# @openng/optimus-ui-mcp

A [Model Context Protocol](https://modelcontextprotocol.io) server that lets coding agents look up [Optimus UI](https://optimus.openng.org) while they work: components by name or selector, their inputs, outputs and templates, the code of every docs example, types such as `MenuItem`, and the guides.

It runs locally over stdio and ships the manifest of its own release, so it works offline and describes the version you install.

## Setup

Claude Code:

```bash
claude mcp add optimus-ui -- npx -y @openng/optimus-ui-mcp
```

Cursor, VS Code, Windsurf and other clients:

```json
{
    "mcpServers": {
        "optimus-ui": {
            "command": "npx",
            "args": ["-y", "@openng/optimus-ui-mcp"]
        }
    }
}
```

Pin the version to the Optimus UI release your project uses, e.g. `@openng/optimus-ui-mcp@2.0.2`.

## Tools

| Tool              | Returns                                                                                                                                       |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | Components, inputs, outputs, types, examples and guides matching a query, each with the tool call that returns the details                   |
| `list_components` | Every documented component with its selectors                                                                                                 |
| `get_component`   | Imports, and per component or directive its selector, inputs (allowed values, defaults, two-way bindings), outputs, templates, methods and examples |
| `get_example`     | The full code of one docs example                                                                                                             |
| `get_type`        | An interface, type alias or class, such as `MenuItem`, `TreeNode` or `DynamicDialogConfig`                                                    |
| `get_guide`       | A guide (installation, configuration, theming, Tailwind, ...), whole or one section                                                          |

All tools are read-only.

## Options

```
optimus-ui-mcp [--manifest <path>]
```

`--manifest` points the server at another `manifest.json`, for example one built from a local checkout with `pnpm --filter docs build:manifest` (written to `apps/docs/public/llms/manifest.json`).

## How it is built

The data is the Optimus UI manifest, generated by `apps/docs/scripts/build-manifest.mjs` from the compiled library typings, and the documentation pages. The same manifest generates the [LLM docs](https://optimus.openng.org/llms) and the Agent Skill, so all of them agree. It is also published at <https://optimus.openng.org/llms/manifest.json>.
